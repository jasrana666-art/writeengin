# AI Business Coach

An interactive chatbot that helps users start businesses using 15 free tools. Built with HTML, CSS, JavaScript, and OpenRouter API.

## Features

- **Business Idea Generator** — AI-powered business ideas based on your skills
- **Free Tools Recommender** — 15 free tools database with recommendations
- **Business Plan Generator** — Complete business plan in minutes
- **Content Calendar** — 30-day content calendar generator
- **Revenue Calculator** — Monthly/annual revenue projections

## Quick Start

1. Open `index.html` in your browser
2. Click a quick action button or type your message
3. Get instant AI-powered business advice

## Setup

### Option 1: Local (No API Key)
- Open `index.html` directly in browser
- Works in demo mode (shows tools database)

### Option 2: With AI (Free API Key)
1. Get free API key from [OpenRouter](https://openrouter.ai)
2. Replace `sk-or-v1-demo` in `index.html` with your key
3. Open in browser — full AI responses enabled

### Option 3: Deploy Online
1. Push to GitHub repo
2. Enable GitHub Pages
3. Share your link
