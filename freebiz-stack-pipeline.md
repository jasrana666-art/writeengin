## Automation Pipeline (Make.com)

### Pipeline 1: Content Creation Workflow
```
ChatGPT (generate content) → Canva (create graphics) → Instagram (schedule post)
```
- **Trigger:** New content idea in Notion
- **Action 1:** ChatGPT se content generate karo
- **Action 2:** Canva se graphics banao
- **Action 3:** Instagram pe schedule karo
- **Time saved:** 2 hours/day

### Pipeline 2: Lead Capture Workflow
```
Wegic (landing page) → Beehiiv (email capture) → HubSpot (CRM entry)
```
- **Trigger:** New signup on landing page
- **Action 1:** Beehiiv mein subscriber add karo
- **Action 2:** HubSpot CRM mein contact create karo
- **Action 3:** Welcome email sequence start karo
- **Time saved:** 30 min/lead

### Pipeline 3: Sales Workflow
```
Gumroad (sale) → Wave (invoice) → HubSpot (deal update) → Toggl (time log)
```
- **Trigger:** New sale on Gumroad
- **Action 1:** Wave mein invoice create karo
- **Action 2:** HubSpot mein deal update karo
- **Action 3:** Toggl mein time log karo
- **Time saved:** 15 min/sale

### Pipeline 4: Social Media Workflow
```
Virality AI (idea) → ChatGPT (caption) → Canva (graphic) → Instagram (post)
```
- **Trigger:** Virality AI se new idea
- **Action 1:** ChatGPT se caption generate karo
- **Action 2:** Canva se graphic banao
- **Action 3:** Instagram pe post karo
- **Time saved:** 1 hour/post
